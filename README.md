RL Fine-Tunable Sparse MoE Baseline

This repository contains a PyTorch-based research scaffold for:

Sparse Mixture-of-Experts Transformer
Top-k routing
Router Adapter fine-tuning
KL-constrained routing
RL-ready router optimization
Latency-aware reward
Experiment comparison and logging

Implemented experiments:

sparse_moe_baseline
adapter_kl
adapter_kl_rl

This scaffold is intended as a prototype baseline before integration into the official Google Research V-MoE repository.
